# CodeType Terminal

## Requirements

- Node.js 18 or newer
- A modern terminal such as Powershell, iTerm2, or a linux terminal

## Run

Open a terminal in this folder and run:

```bash
npm start
```
If this command does not work, try:

```bash
npm.cmd start
```

No installation or external packages are required.

## Controls

- Type the displayed code normally.
- **Enter** inserts the target newline and its indentation automatically.
- **Backspace** removes the previous character smartly as it would do in a programming environment.
- **Tab** loads the next snippet.
- **Esc** restarts the current snippet.
- **Ctrl+C** exits.
- **Alt+C** essentially performs the back arrow should've this been made as a website as opposed to a terminal app.

At startup, choose a language and then choose **short**, **medium**, **long**, or **thicc**. A random source exercise from that category will load. (lets be real it's not random it's in an order but whatever lol)

During pracice, press **Tab** for another "random" file in the same category, or **Alt+C** to return to the language menu.

The bundled source repositories are listed in `SOURCES.md`.
